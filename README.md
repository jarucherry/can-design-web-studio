# CAN DESIGN WEB STUDIO — เว็บแนะนำตัวสำหรับรับทำเว็บไซต์

เว็บหน้าเดียว (HTML/CSS/JS ธรรมดา ไม่ต้องติดตั้งอะไร) พร้อมหน้าแอดมิน และเว็บตัวอย่าง 17 ธุรกิจ

## เปิดดู

- หน้าเว็บ: ดับเบิลคลิก `index.html`
- หน้าแอดมิน: ดับเบิลคลิก `admin.html`

## แก้ข้อมูลและข้อความ (หน้าแอดมิน)

เปิด `admin.html` จะมีแถบสำหรับแต่ละส่วนของเว็บ: ข้อมูลและติดต่อ, ส่วนหัว, ผลงาน, ตัวอย่างดีไซน์,
ทำไมต้องเรา, บริการ, ราคา, ส่วนติดต่อ ทุกข้อความกรอกได้สองภาษา (ไทยและอังกฤษ)
รายการต่าง ๆ เพิ่ม ลบ และเลื่อนลำดับได้

**เผยแพร่จากหน้าแอดมินได้เลย** (เปิด https://jarucherry.github.io/can-design-web-studio/admin.html ได้จากทุกที่):
ตั้งค่าครั้งเดียวที่แถบ "เผยแพร่" (ใส่ GitHub token ตามขั้นตอนในแถบนั้น) แล้วกด **เผยแพร่ขึ้นเว็บ**
เว็บจริงอัปเดตเองภายใน 1–2 นาที รูปบทความอัปโหลดผ่านปุ่ม "อัปโหลดรูป" ได้เลย

ถ้ายังไม่ได้ตั้งค่า ใช้วิธีเดิมได้:

1. แก้ข้อมูล — ระบบเก็บเป็น "ฉบับร่าง" ในเบราว์เซอร์นี้ทันที
2. กด **ดูตัวอย่าง** — เปิดหน้าเว็บที่แสดงฉบับร่าง (มีแถบสีเข้มด้านบนบอกว่าเป็นฉบับร่าง)
3. กด **บันทึกไฟล์ content.js** — ใน Chrome/Edge จะถามที่บันทึก ให้เลือกไฟล์ `content.js` ในโฟลเดอร์นี้เพื่อเขียนทับ
   (เบราว์เซอร์อื่นจะดาวน์โหลดไฟล์มาให้ นำไปวางแทนไฟล์เดิมเอง)
4. อัปโหลด `content.js` ขึ้นเว็บจริง

**สำคัญ:** เว็บนี้ไม่มีเซิร์ฟเวอร์เก็บข้อมูล ผู้เข้าชมจะเห็นการแก้ไขก็ต่อเมื่อไฟล์ `content.js` ที่บันทึกแล้ว
ถูกอัปโหลดขึ้นเว็บจริง ฉบับร่างเห็นได้เฉพาะในเบราว์เซอร์ที่แก้เท่านั้น
ด้วยเหตุเดียวกัน หน้าแอดมินจึงไม่มีรหัสผ่าน: คนอื่นเปิดได้ แต่แก้เว็บจริงไม่ได้

รูปภาพ: วางไฟล์ไว้ในโฟลเดอร์ `assets/` แล้วพิมพ์ชื่อไฟล์ในช่อง "ไฟล์รูป" เช่น `assets/work-shop.jpg`

## ไฟล์

| ไฟล์ | คืออะไร |
| --- | --- |
| `articles/` | หน้าบทความ สร้างจาก content.js อัตโนมัติ ห้ามแก้ไฟล์ในนี้ตรง ๆ |
| `tools/build-seo.js` | สร้างส่วน SEO ใน index.html, sitemap.xml, robots.txt, llms.txt จาก content.js |
| `content.js` | เนื้อหาทั้งหมดของเว็บ (ชื่อ ติดต่อ ข้อความ ราคา) — หน้าแอดมินเป็นคนเขียนไฟล์นี้ |
| `index.html`, `main.js`, `styles.css` | หน้าเว็บ วาดจาก `content.js` |
| `admin.html`, `admin.js` | หน้าแอดมิน |
| `demos/` | เว็บตัวอย่าง 17 ธุรกิจ: cafe, hostel, spa, nails, clinic, dental, tutor, contractor, gym, pet, property, photo, carrental, cake, accounting, garage, wholesale และ `ninelives` (ภาพหน้าจอเว็บโรงงานแมวเก้าชีวิต ผลงานจริงที่ยังไม่เปิดใช้) |
| `assets/` | รูปผลงาน รูปตัวอย่าง และโลโก้ขนาดต่าง ๆ (`logo-96/192/640.webp`, ไอคอนแท็บ) |
| `brand/` | โลโก้ต้นฉบับ รูปโปรไฟล์และรูปปกสำหรับเพจ Facebook |

หน้าเว็บพื้นขาวอุ่น ตัวหนังสือสีม่วงเข้ม เส้นสีทองตามขอบโลโก้ ใช้สีรุ้งพาสเทลเฉพาะที่โลโก้และแสงเบา ๆ ด้านหลัง กำหนดไว้ต้นไฟล์ `styles.css`

## เว็บตัวอย่าง

มีแถบด้านบนบอกว่าเป็นตัวอย่าง ไม่ใช่ธุรกิจจริง และตั้งค่าไม่ให้ Google เก็บไปแสดง
แต่ละแบบมีฟังก์ชันที่ใช้งานได้ (สั่งเมนู คิดราคาห้องพัก จองคิว ประเมินราคา ฯลฯ) และสลับภาษาไทย/อังกฤษได้
ปุ่ม "ส่งทาง LINE" แสดงข้อความที่จะส่งให้ดูแทนการส่งจริง (อยู่ใน `demos/demo.js`)
ราคา อัตรา และคิวว่างในตัวอย่างเป็นตัวเลขสมมติ

ทุกเว็บตัวอย่างมีแผนที่ Google Maps และปุ่ม "เปิดใน Google Maps" วิธีใส่: วาง
`<div class="dm-map" data-q="ชื่อสถานที่หรือที่อยู่"></div>` ในหน้า แล้ว `demos/demo.js` จะสร้างแผนที่ให้ ไม่ต้องใช้ API key
ตำแหน่งในตัวอย่างเป็นย่านจริงที่เลือกมาแทนร้านสมมติ เมื่อทำให้ลูกค้าจริง ให้ใส่ชื่อร้านหรือที่อยู่ของเขาใน `data-q`

คำแปลของแต่ละหน้าอยู่ในบล็อก `Demo.en({...})` ต้นสคริปต์ของหน้านั้น ถ้าแก้ข้อความไทยในหน้า
ต้องแก้คีย์ในบล็อกนี้ให้ตรงกันด้วย ไม่อย่างนั้นข้อความนั้นจะไม่ถูกแปล

## SEO และการค้นหาด้วย AI

หน้าเว็บวาดด้วย JavaScript แต่ Google รอบแรกและเครื่องมือ AI ส่วนใหญ่ (ChatGPT, Claude, Perplexity) ไม่รัน JavaScript
จึงต้องมีสำเนาเนื้อหาแบบ HTML ธรรมดาอยู่ใน `index.html` ด้วย พร้อมข้อมูลโครงสร้าง (schema.org) ของสตูดิโอ ราคา และคำถามที่พบบ่อย

ทุกครั้งที่ push ขึ้น GitHub (รวมถึงกด "เผยแพร่ขึ้นเว็บ") GitHub จะรันสคริปต์นี้ให้เองก่อนขึ้นเว็บ (`.github/workflows/publish.yml`)
ถ้าจะดูผลในเครื่องตัวเอง รัน:

```
node tools/build-seo.js
```

สคริปต์นี้เขียนส่วน SEO ใน `index.html` ใหม่ และสร้าง `sitemap.xml`, `robots.txt`, `llms.txt` (สรุปเว็บสำหรับ AI) ตามเนื้อหาล่าสุด
ข้อความที่แสดงในผลการค้นหาแก้ได้ที่แถบ "SEO" ในหน้าแอดมิน ที่อยู่เว็บอยู่ในแถบ "ข้อมูลและติดต่อ"
